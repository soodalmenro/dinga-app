# 동작 줄이기와 확대 팝업 가독성

2026-11-13. 실기 결과 없이 구현·검증할 수 있는 접근성 보강이다.

## 구현한 동작

- 기기·브라우저의 `prefers-reduced-motion`이 켜져 있으면 캐릭터 진입·대기·터치 애니메이션과 축하 색종이를 실행하지 않는다. 캐릭터 이미지와 대사·버튼 기능은 유지한다.
- 앱을 열어 둔 상태에서 설정을 켜면 진행 중인 캐릭터 모션과 색종이 프레임을 취소하고 캔버스를 비운다. 다시 끄면 기본 모션을 사용할 수 있다.
- 화면을 나갈 때 설정 구독과 해당 캐릭터의 진행 중 애니메이션을 정리한다. 이전 진입 모션의 늦은 완료 이벤트가 새 대기 모션을 만들지 않도록 한다.
- CSS 화면 전환·반복 장식과 스크롤도 같은 설정을 따른다. 출석·레슨·곡의 시간과 판정 수식은 바꾸지 않는다.
- 팝업 제목·설명·큰 버튼은 가능한 한 한글 단어 경계로 줄바꿈한다. 긴 단어는 필요하면 나누고 버튼에 세로 여백을 제공한다. 짧은 가로 화면에서는 팝업 안에서 스크롤해 조작할 수 있다.

## 확인 도구

`qa/motion-accessibility.cjs`는 실제 브라우저의 미디어 설정을 바꿔 초기 감소 설정·기본 모션·터치 반응·사용 중 전환·복원·구독 해제를 확인한다. 기존 코드에서 감소 설정에도 캐릭터 모션이 남고 사용 중 변경이 반영되지 않는 실패를 확인한 뒤 수정했다.

`qa/recovery-layout.cjs`는320×568·844×390·568×320에서 확대 글자와 복구 버튼 조작을 검사한다. 캡처를 통해 한 글자만 다음 줄로 떨어지던 버튼의 줄바꿈도 확인한다. 기존 품질·모바일·참가자 전달 검사를 함께 실행한다.

이 검사는 Windows Edge를 사용한다. 실제 휴대폰의 접근성 설정 전달 방식과 보조기기 사용성은 마지막 기기 검증 범위다. 자동 검사 통과만으로 모든 브라우저의 접근성 적합성을 주장하지 않는다.

브라우저 검사에서 초기 감소·기본 모션·설정 변경/복원·탭·구독 해제가 통과했다. 구형 `addListener` 방식도 같은 변경/정리 검사를 통과했다. 모바일12개 조합, 확대/가로 팝업3개, 품질10개와 참가자 설정·기록 보존 검사, 두 빌드와 로컬 배포 파일 검사도 통과했다. 전체 회귀 첫 실행은 곡 리포트 대기에서 시간 초과되어 실패 상태 진단을 추가하고 재검증한다. 해당 실패의 원인은 아직 확정하지 않았다.

같은 제품 소스와 빌드로 전체 회귀를 재실행해140개 모두 통과했다. 첫 시간 초과는 재현되지 않았으며 원인을 추정해 제품 코드를 바꾸지는 않았다. 이후 실패 시 화면 가시성·마지막 화면·최근 이벤트 종류를 남기도록 QA 진단을 유지한다.
