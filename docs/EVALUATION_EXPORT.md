# 평가 기록 회수

2026-11-12. 평가 패널은 화면 오른쪽 위를 빠르게 세 번 누르면 열린다. 실기 검증은 마지막에 진행하며, 그때 참가자별 파일을 회수한다. 파일은 브라우저에서 직접 만들고 서버에 업로드하지 않는다.

## 사용 순서

1. 참가자 번호를 입력하고 평가를 진행한다. 한 세션 도중에는 참가자 번호를 바꾸지 않는다.
2. 평가 종료 후 평가 패널 → **파일 저장 범위: 현재 참가자** → **JSON 저장**을 누른다.
3. 브라우저의 다운로드를 확인한다. 화면의 ‘파일 저장 요청’은 실제 기기의 저장 완료를 보증하는 문구가 아니다. 아래 같은 내용의 JSON을 직접 선택해 복사할 수도 있다.
4. 참가자가 바뀌기 전 파일을 회수한 뒤 상태 초기화를 실행하고 다음 참가자 번호를 입력한다. 상태 초기화는 행동 기록을 지우지 않는다.
5. 모든 기록이 필요할 때만 파일 저장 범위를 ‘전체 참가자’로 바꾼다. 번호가 비어 있으면 ‘미지정’ 기록만 현재 참가자 범위에 포함한다. 공백과 대소문자까지 정확히 비교한다.

기존 **복사** 버튼은 전체 참가자의 행동 기록 배열을 복사하는 형식을 유지한다. JSON 파일의 범위 선택과는 별도다. 복사가 성공했는지 실제 응답을 확인해 표시하고, 거부·미지원·2초 무응답이면 수동 선택 안내를 표시한다. 참가자·파일 범위 변경이나 비우기·닫기 이후의 늦은 응답은 이전 출력 안내를 되살리지 않는다.

## JSON schemaVersion 1

| 항목 | 의미 |
|---|---|
| `schemaVersion`, `exportedAt` | 파일 형식 버전과 내보낸 시각(UTC) |
| `scope`, `participant` | 참가자별/전체 범위. 전체일 때 participant는 null |
| `app.bundle` | 파일을 내보내는 현재 앱의 JS 자산 경로. 과거 이벤트 버전으로 해석하지 않는다 |
| `environment` | 기본 브라우저 User-Agent와 HTTPS·클립보드·미디어 API 지원 여부. 권한 허용 여부와는 다르다 |
| `settingsAtExport` | 내보낸 시점의 화면 구성·판정·자세 알림·속도·날짜 이동 설정. 이전 세션 설정으로 추정하지 않는다 |
| `retention` | 보관 상한4000건, 이전 기록 누락 가능성, local/memory/unavailable/unknown 저장 출처 |
| `summary` | 선택한 유효 이벤트 개수·종류·참가자 수, 무효 이벤트와 버전 불명 이벤트 수, 첫/마지막 기록의 시각 |
| `events` | 선택한 범위의 허용된 행동 기록. 브라우저 기록 순서 유지 |

새 이벤트의 `bundle`은 당시 실행한 앱의 JS 자산 경로다. 과거 이벤트나 개발/단일 파일 실행에서 버전을 확인할 수 없으면 비워 두며 `unversionedEvents`로 집계한다. 정보를 소급 보충하지 않는다. 현재 상태의 출석·기록·마지막 리포트는 참가자 귀속을 보장할 정보가 없어 파일에 포함하지 않는다. 이 파일은 계정 백업·복원 파일이 아니다.

새 `songplay_end` 이벤트에는 다음 진단이 포함된다.

- 전체/부분 완주 여부와 실제/모의 판정 방식
- 마디별 목표 코드, 박자 결과, 코드 결과(true/false/null)
- 확인된 코드, 판정 보류 이유, 판정 알고리즘 버전
- 마이크 미사용(`no-microphone`), 소리 미감지(`no-onset`), 모의 판정(`simulated`) 구분

이전 종료 이벤트에는 상세 진단이 없을 수 있다. 알 수 없는 과거 결과를 새 알고리즘의 판정으로 재해석하지 않는다.

## 보관과 정보 범위

최근4000개 이벤트까지 보관한다. 상한에 도달하면 이전 기록이 일부 없을 수 있다는 안내와 파일 표시를 제공한다. 참가자마다 파일을 회수한다. 저장 공간 부족으로 행동 기록만 메모리에 남는 경우에도 평가 패널에서 안내하고 그 내용을 파일로 회수할 수 있다. 창을 닫은 뒤에는 메모리 기록을 복구할 수 없다. 저장소를 읽지 못하는 경우에는 파일이 비어 있거나 일부일 수 있다고 안내한다.

내보내기는 허용된 필드만 사용한다. 원음·영상·관절 좌표 배열·주파수 배열·RMS 샘플·장치 식별자·입력 보정 수치는 포함하지 않는다. 참가자 번호는 사용자가 입력한 값 그대로 포함한다. 실제 사용자 이름 등 식별 정보를 번호로 입력했다면 파일에도 들어가므로 연구용 참가자 코드를 사용한다.

## 검증 범위

- `qa/evaluation-export-unit.cjs`: 참가자/전체/미지정 범위, 스키마·요약, 허용 필드와 중첩 진단, 파일명, 버전 불명·보관 상한, 잘못된 입력, 복사 성공/거부/미지원/무응답.
- `qa/evaluation-export-browser.cjs`: 실제 JSON 다운로드 내용, 범위 전환·참가자 변경, 같은 파일 미리보기, 수동 복사, 저장 실패 임시 기록 회수, 늦은 응답과 비우기/닫기, 320px 배치·가독성,4000건 파일.
- 기존 참가자 교체, 저장 복구, 코드 판정 보류 진단, 품질 회귀10개와 전체 QA140개를 확인했다. 별도 읽기 전용 검토에서도 확정된 회귀는 없었다.

브라우저 검증은 Windows Edge에서 수행했다. 실제 iOS/Android의 파일 저장·공유 동작과 실기 결과는 마지막 휴대폰 검증 항목이다.
