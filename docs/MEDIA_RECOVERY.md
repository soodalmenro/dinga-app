# 입력 중단 복구와 코드 전환 검증

2026-11-13. 실제 휴대폰·기타 검증 전에 진행한 소프트웨어 보강이다.

## 마이크가 끊겼을 때

트랙 종료·일시 중단·스트림 종료와 오디오 처리 장치 중단을 감지하면 입력을 해제하고 연습을 멈춘다. 입력 없는 시간을 연주 성공으로 세지 않는다. 사용자가 ‘마이크 다시 연결’을 눌러 연결하고, ‘연습 계속하기’를 눌러야 재개한다. 재연결 권한이 거부돼도 자동으로 진행하지 않는다. 대기 중 마이크 없이 진행하거나 나갈 수 있으며, 취소 뒤 도착한 스트림은 해제한다.

- 출석은 실제 관측한 소리만 누적하며, 수동 출석도 선택할 수 있다.
- 레슨은 멈춘 단계에서 이어간다. 연결 중단과 화면 전환이 함께 발생해도 한 번의 명시적 계속하기로 재개한다.
- 12마디 곡 연습은 완료한 마디를 보존하고 미완료 마디부터 다시 측정한다. 마이크 없이 계속하면 이후 입력은 미측정으로 처리하고 실제 판정 최고 기록을 갱신하지 않는다.
- 8마디 전환 연습은 연결 복구 시 미완료 마디부터 이어간다. 마이크 없이 모의 판정으로 전환하면 이번 시도를 처음부터 다시 시작한다. 실제 입력과 모의 결과를 한 시도에 섞지 않는다.
- 입력이 중단되면 임시 마이크 보정도 해제한다. 같은 장치라도 다시 환경 확인을 진행할 수 있다.

브라우저에서 권한을 영구 차단했다면 사이트 권한을 직접 변경해야 한다. 자동 재요청으로 권한 창을 반복해서 열지 않는다.

## 카메라와 화면 복귀

레슨 미리보기·PRD 촬영·환경 확인에서 카메라 트랙이 끊기면 기존 추적과 스트림을 정리하고 재시도를 제공한다. 촬영 카운트다운 중 끊기면 자세 결과를 저장하지 않는다. 모델 준비 중 끊긴 경우 늦은 초기화 응답으로 추적을 다시 시작하지 않는다. 선택적인 카메라 중단이 기타 연습을 강제 종료하지는 않는다.

자세 계산과 촬영 안내는 좌표·가시성의 유효성 검사를 공유한다. 화면 밖 좌표, NaN·Infinity, 잘못된 가시성, 0 이하 영상 크기로 자세 경고를 만들지 않는다. 안내에는 추가 화면 여백이 있으며, 일부 부위가 가려지면 계산 가능한 부위만 사용한다.

반복된 화면 숨김 이벤트는 최초 중단 시점을 유지한다. 연습 중 화면 꺼짐 방지 요청은 화면 복귀 시 다시 시도하고, 시스템이 해제하면 다음 사용자 조작에서도 재시도한다. 연습 종료 뒤 늦게 도착한 잠금은 해제한다. 운영체제의 화면 잠금 방지 지원과 승인은 보장할 수 없다.

## 이전 코드의 잔상을 다음 코드로 판정하지 않기

합성 입력에서 ‘큰 이전 코드 → 짧고 작은 다음 코드’를 넣었을 때 기존 분석기는 10개 조건 중 6개에서 이전 코드를 확정했다. 마디별 샘플을 분리하고 첫 소리 이후 새 FFT 창이 채워진 시점부터 수집하도록 수정했다. 주파수 분석기의 시간 평활화도 0으로 바꿔 이전 창의 잔상을 제거한다. 마디 안의 유효 샘플 합산은 유지한다.

44.1kHz·48kHz의 짧은 어택·감쇠·코드 전환 10개 조건은 새 코드 또는 판정 보류를 허용하며, 이전 코드를 확정하지 않아야 한다. 짧은 입력을 억지로 정답 처리하지 않는다. 새 분석 창을 확보하지 못하면 `insufficient-window`로 보류하고, 이 이유는 평가 JSON에도 남는다. 기존 `chroma-guard-v1` 분류 수식과 임계값은 유지한다.

원음·영상·주파수 배열을 저장하거나 업로드하지 않는다.

## 재현 도구

| 명령 | 검사 내용 |
|---|---|
| `node qa/lifecycle-core.cjs` | 트랙 유효성·리스너 해제·잠금 중복·늦은 응답·화면 복귀 |
| `node qa/pose-input-validity.cjs` | 화면 밖·잘못된 좌표/가시성/영상 크기·비정상 판정 값 |
| `node qa/bar-spectrum-unit.cjs` | 새 창 대기·짧은 입력·마디 격리·초기화 |
| `node qa/media-recovery.cjs` | 연결 중단·거부·재시도·명시적 재개·늦은 응답·모의 전환·화면 복귀 |
| `node qa/camera-track-loss.cjs` | 촬영 중단·모델 준비 중 중단·늦은 응답 무시·재연결 |
| `node qa/chord-transients.cjs` | 실제 오디오 분석 경로의 합성 어택·감쇠·전환 10개 조건 |
| `node qa/chord-audio.cjs` | 기존 지속 합성음 20개 조건 |

브라우저 검사는 Playwright와 Edge/Chromium의 가상 장치를 사용한다. 합성 입력 통과는 실제 기타 인식률을 뜻하지 않는다. 실제 기기의 권한 취소·전화 수신·블루투스 전환·Safari 오디오 재개 정책, 기타의 배음·튜닝·소음, 가림·조명·발열은 마지막 실기에서 확인해야 한다. 운영체제별 중단 이벤트와 재연결 허용 방식도 다를 수 있다.

11/13 최종 로컬 검증에서 위 신규 검사, 기존 전체 QA 140개, 품질 10개, 모바일 12개 조합, 환경·자세·저장·평가 내보내기, 지속 합성음 20개와 과도 입력 10개가 통과했다. 일반·단일 파일 빌드와 배포용 번들의 복구 스모크도 통과했다. 별도 읽기 전용 코드 리뷰에서 추가로 확정된 중요한 오류는 없었다.
