# 연습 환경 확인

2026-11-12. 홈의 **연습 환경 확인**에서 선택적으로 사용한다. 확인 없이도 기존 출석·레슨·곡 연습을 이용할 수 있다. 실제 기타와 휴대폰 검증은 마지막에 진행한다.

## 마이크 입력 준비

1. ‘마이크 확인하기’를 누르고 권한을 허용한다. 화면을 열기만 해서는 권한을 요청하지 않는다.
2. ‘잠시 조용히 있어 주세요’에서 2초 동안 기타를 치지 않는다.
3. ‘기타 줄을 한 번 튕겨 주세요’에서 시험 연주를 한다. 2초 동안 입력을 확인한다.
4. 소음과 시험 소리가 구분되면 ‘이 기준으로 사용하기’를 선택한다. 소음이 크거나 소리가 부족하면 다시 확인하거나 기본 기준을 사용한다.

기본 기준은 RMS 0.05다. 소음 샘플의 95백분위 값을 사용해 `max(0.05, noise95 × 2.5 + 0.01)`을 후보로 만든다. 후보가 0.15보다 높으면 적용하지 않는다. 각 단계 30개 이상 유효 샘플과 후보 기준을 넘는 시험음 2샘플 이상, 후보의 1.8배 이상 시험음 최대값이 필요하다. RMS 0.95 이상 과도한 입력과 잘못된 값도 거절한다. 이 수치는 실기 보정 전의 공학적 시작값이다.

- 보정은 기본 기준을 낮추지 않는다. 코드 종류를 맞추는 알고리즘과 별개로 소리 크기를 구분하는 기준만 바꾼다.
- 적용 후 최대 10분, 같은 입력 장치에서만 사용한다. 기본 장치 별칭은 장치 그룹도 구분한다. 장치를 식별할 수 없으면 현재 캡처 연결에서만 사용한다.
- 보정값은 메모리에만 있다. 새로고침·참가자 상태 초기화·만료 후 기본값을 사용한다. 실행 중 감지기도 만료를 반영한다.
- 원음·RMS 샘플·보정 수치·장치 식별자는 저장하지 않는다. 행동 기록에는 확인 성공/실패 이유와 적용 행동만 남긴다.
- 탭 숨김·250ms 초과 관측 공백·마이크 종료가 생기면 확인을 중단한다. 관측하지 못한 시간을 소음 측정으로 계산하지 않는다.

## 카메라 촬영 위치

‘카메라 확인하기’를 누르면 미리보기와 관절 인식을 통해 안내한다. 폰을 고정하고 두 어깨와 코드 잡는 팔·손이 함께 보이게 둔다. 처음에는 자세 모델 준비 시간이 필요할 수 있다.

| 보이지 않는 조건 | 안내 |
|---|---|
| 상체 인식 없음 | 상체를 화면 안으로 옮기고 빛이 얼굴 쪽으로 오게 조정 |
| 한쪽 어깨가 가려지거나 화면 밖 | 폰을 뒤로 옮겨 두 어깨를 포함 |
| 어깨 사이 폭이 영상 너비의 12% 미만 | 폰을 조금 가까이 두기 |
| 귀가 보이지 않음 | 머리와 어깨가 함께 보이도록 폰 높이 조절 |
| 코드 잡는 팔꿈치·손목·손끝이 안 보임 | 기타 가림을 줄이도록 폰 각도 조절 |

‘확인할 부위가 보여요’는 **올바른 자세 판정이 아니다.** 좌표·가시성과 화면 범위를 보는 준비 안내다. 밝기나 실제 거리의 정확한 측정도 아니다. 카메라 확인에서는 자세 경고를 띄우지 않으며, 연습의 기본 ‘정해진 시점’ 알림 설정도 바꾸지 않는다.

실제 자세 판정을 선택한 레슨에서는 해당 레슨의 손목/어깨 중심 항목에 맞춰 촬영 안내를 제공한다. 카메라를 켰지만 필요한 부위가 보이지 않는 상태와 자세가 잘못된 상태를 구분한다. 영상은 저장하지 않는다.

## 중단과 복구

마이크·카메라 각각 중단·재시도할 수 있다. 권한 응답이 늦으면 확인 마치기로 나가도 된다. 나간 뒤 도착한 스트림은 해제한다. 카메라 모델 초기화나 추적 실패 시 영상 스트림도 중단한다. 다른 화면/앱으로 전환하면 확인을 멈추며 자동으로 다시 시작하지 않는다.

## 검증과 남은 한계

- `qa/practice-environment-unit.cjs`: 보정 유효성, 소음·약한 신호·과도 입력·이상값·스파이크, 장치/그룹/세대·시간 만료·초기화, 가림/화면 밖/거리/레슨별 촬영 요구.
- `qa/pose-framing.cjs`: 실제 watcher 경로가 레슨 중심 항목을 촬영 안내에 전달하는지 확인.
- `qa/practice-environment.cjs`: 명시적 권한 요청, 보정 적용·실행 중 만료, 취소 후 늦은 응답, 거부·잡음·약한 입력·기본 복귀, 숨김/프레임 공백, 카메라 실패 자원 해제·재시도, 대기 중 화면 종료, 수치 비저장과 320/360/390px 화면 검사.

자동 검사는 가짜 장치와 관절 좌표를 사용한다. 실제 휴대폰의 소음 분포·기타 감쇠·마이크 특성, 기타에 의한 가림, 체형·조명·발열은 확인하지 않았다. 소음이 변하면 재확인하고, 실제 기타에서 과도한 누락이나 감지가 있으면 기종·환경·화면 안내와 함께 기록한다.

최종 검증에서 위 환경 준비 검사와 기존 전체 QA140개, 품질 회귀10개, 모바일 화면12개 조합, 자세 모델 복구, 저장 복구·코드 판정 보류 호환 검사, 합성 오디오20개가 통과했다. 두 빌드와 의존성 감사(0건)도 확인했다. 읽기 전용 재검토에서 발견한 실패 후 카메라 자원 유지와 레슨 중심 항목 누락을 수정하고 회귀 검사를 통과했다.
