# 파트 선택 모달 마무리

2026-11-14. [Figma 코드 레슨80:16](https://www.figma.com/design/7P8BU0iGlHRnj52Z7q1JBb/?node-id=80-16)과 [완주하기80:172](https://www.figma.com/design/7P8BU0iGlHRnj52Z7q1JBb/?node-id=80-172)의 코드·스크린샷을 확인하고 기존 React/CSS 화면에 적용했다.

## 반영 범위

- 아이디어 구성의 Em/G/C 파트 선택에 손을 흔드는 캐릭터, 완주하기에 뛰는 캐릭터를 배치했다. 기존 `hi.webp`·`yay.webp`가 원본과 같은 그림임을 확인해 재사용했다. 장식은 보조기술에서 숨기고 터치/초점 대상에서 제외한다.
- 모달 배경색은 원본 SVG 메타데이터의 `#34324A`다.390px 화면에서 흰 시트 폭350px, 내부 여백20px, 카드 간격14px, 코드 카드 최소88px·완주 카드 최소96px로 맞췄다. 짧은 화면은 시트만 스크롤하고 장식을 위한 위아래 공간을 남긴다.
- 완료 체크·닫기·다음 화살표는 Figma 제공 SVG를 로컬 파일로 내려받았다. 원본20/18/18px 크기를 보존했다. 닫기 버튼의 터치 영역은44px다.
- 기본 구성의 파트2와 완료 안내를 ‘코드 잡기’로 통일했다. PRD 비교 구성의 ‘코드 만들기’와 원본 학습 정의 객체는 유지해 화면 구성 전환의 이어하기 매핑을 건드리지 않았다.
- 완주하기의 Em/G/C 배지를 추가했다. 원본 화면의 옛8마디 문구는 최신 개발 전달9절에 맞는 현재12마디 내용으로 유지한다. 본문 색과 Pretendard 폰트도 기존 가독성 보강을 유지하므로 전체 앱의 픽셀 일치를 주장하지 않는다.

## 키보드와 회귀

공통 Modal에는 선택적인 장식 슬롯과 클래스만 추가했다. 시트의 dialog 이름, 초점 가두기, Escape·바깥 클릭·닫기, 스크롤은 유지한다. 다른 팝업은 기존 렌더링 경로를 따른다.

‘코스 이어하기’는 목록을 상세 화면으로 바꾸므로 처음 누른 버튼이 사라진다. 닫으면 해당 레슨 카드로 초점을 복귀한다. 작은 화면에서 카드가 스크롤 영역 밖이면 실제로 보이도록 복귀해야 한다. 이 조건은 별도 회귀 검사로 확인한다.

`qa/course-modal.cjs`는390/320/430px 세로,667×320 가로,320px 큰 글자와 PRD 비교를 포함한11개 조건에서 장식·자산·시트 수치·가로 넘침·마지막 카드 접근·3가지 닫기·초점 복귀를 검사한다. 최종 빌드/회귀/배포 결과는 [작업 계획](superpowers/plans/2026-11-14-course-modal-polish.md)의 Ledger에 남긴다.

실제 카메라·기타 인식 임계값과 점수·시간·저장 형식은 이번 시각 정리 범위에 포함하지 않는다. 실기 검증은 마지막에 진행한다.
