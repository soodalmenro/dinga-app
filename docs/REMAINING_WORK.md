# 개발 마무리와 마지막 실기 범위

2026-11-14 코스 대조와 후속 모달 시각 정리 기준. 새 기능을 계속 늘리는 계획이 아니라 현재 코스1 연구용 프로토타입의 범위다.

이번 보강: 기획/Figma와 코스1 전체12파트를 대조하고, 두 구성24파트의 정상 버튼 동선을 끝까지 확인했다. 전환의 상단 진행 표시와 코스 마지막 파트180초 적립을 수정했다. 전체140개·전환 진행3개·곡 완료9개·모바일12개 등 회귀 검사를 통과했다. 자세한 근거와 기존 시각 차이는 [COURSE_AUDIT.md](COURSE_AUDIT.md)에 기록한다.

운영 배포와 검증 결과는 최신 작업 계획의 Ledger를 따른다. 실제 마이크/카메라의 기타 인식률은 이 자동 검사로 확정하지 않는다.

이전에45~90분으로 남겼던 모달 캐릭터·여백·아이콘·배지·파트 제목 정리를 반영했다. 작은/가로 화면·큰 글자·스크롤·키보드 조건과 닫기 후 보이는 초점 복귀를 검사했다. 상세 범위는 [COURSE_MODAL.md](COURSE_MODAL.md), 최종 회귀·배포 상태는 [마무리 작업 계획](superpowers/plans/2026-11-14-course-modal-polish.md)에 남긴다.

현재 합의된 범위에서 별도로 예정한 실기 전 기능/시각 개발 목록은 없다. 이것은 실제 인식 정확도가 검증됐다거나 결함이 전혀 없다는 뜻은 아니다. 새로운 큰 기능이나 의도적으로 제외한 서버/친구 동기화·코스2/3·엄지 판정·오프라인 실행을 추가하지 않는다.

실제 기타·평가용 휴대폰 검증은 이 작업 뒤의 마지막 단계로 유지한다. 1~2시간의 검증 세션을 예상하되, 기기 준비/참가자 일정은 포함하지 않는다. 결과에 따른 기준값·권한·성능 보정은 반나절~2일 정도의 여유를 본다. 인식 정확도 문제의 크기는 실기 전 확정할 수 없다.

예전 진행상황 문서 하단의 ‘GitHub/Vercel 만들기’ 같은 누적 작업 목록은 과거 기록이다. 현재 구현/배포 범위는 HANDOFF.md와 최근 작업 계획의 검증 기록을 따른다.
