## 제공하는 기능

| 영역 | 구현 내용 |
|---|---|
| 시작·홈 | 모의 폰 홈 화면과 위젯, 스플래시, 5단계 캐릭터 표정, 연속 출석, 출석 후 이어하기 |
| 환경 확인 | 홈에서 선택적으로 소음·시험음 확인과 임시 입력 기준 적용, 카메라 위치 안내. 권한 취소·실패·중단·복구 |
| 출석 | 소리 누적 2초 감지, 10초 미감지 안내와 재시도·건너뛰기, 수동 출석, 당일 중복 방지 |
| 학습 | 코스 1의 Em·G·C와 완주하기, 총 12파트, 완료 표시와 중단 위치 재개 |
| 레슨 | 설명·운지·소리 감지·박자·안 보고 치기·코드 전환, 막혔어요와 나가기 처리 |
| 전환 연습 | 두 코드를 2마디씩 번갈아 8마디, 템포 40~125%, 결과와 직전 비교 |
| 곡 연습 | 인트로·1절·후렴 각 4마디, 현재 마디 강조·스크롤, 메트로놈·일시정지·끝내기 |
| 곡 리포트 | 점수·정확도·구간·전환 결과, 전환 연습 후 원래 리포트 복귀 |
| MY·기록 | 출석일과 총 연습 시간, 1분 이상 연습한 날의 기타 아이콘, 출석 없이 연습한 날의 시간 표시 |
| 친구 | 같은 곡 완료 표시, 샘플 친구 3명, 콕 찌르기 안내 |
| 평가 운영 | 숨은 패널, 참가자 번호, 전체 행동 기록 복사·실패 안내, 참가자별/전체 JSON 회수, 보관 상한·임시 기록 안내, 상태 초기화, 평가 모드 설정 |
| 저장·복구 | 폰 브라우저 로컬 저장, 이전 데이터 기본값 보충, 손상 필드 처리, 저장 실패 안내·재시도 |
| 배포 | GitHub main에 업로드하면 Vercel 운영 배포 실행 |

코스 2·3은 기획에 따라 잠긴 다음 코스로 표시한다. 평가용 콘텐츠는 코스 1이다.

## 판정 방식과 평가 시 설정

| 기능 | 현재 동작과 실기 확인 항목 |
|---|---|
| 자세 알림 기본값 | 연주 단계 시작 5초 뒤 한 번 표시하는 시뮬레이션 |
| 실제 자세 판정 | 패널에서 ‘실제 판정’ 선택. 왼손 손목과 어깨를 계산한다. 기타에 의한 가림과 기기별 정확도는 실기 확인 대상 |
| 카메라 복구 | 권한 거부·모델 실패·응답 멈춤·트랙 중단 안내와 재시도. 촬영 중단 시 결과 미저장, 종료 시 자원 해제 |
| 12마디 코드 판정 | 소리의 음 구성으로 Em·G·C를 추정한다. 실제 기타 정확도는 실기 확인 대상 |
| 12마디 마이크 미사용 | 점수·정확도를 ‘측정 안 됨’으로 표시. 완주·시간을 기록하고 최고 점수는 유지 |
| 12마디 최고 점수 | 실제 마이크 판정으로 완주한 결과만 갱신. 모의·중도 종료는 제외 |
| 코드 판정 보류 | 소리는 있지만 코드가 불명확하면 오답과 구분. 박자·완료는 유지, 코드·종합 점수와 최고 기록 갱신은 보류 |
| 중단·백그라운드 | 팝업·장치 중단 시 일시정지. 재연결과 명시적 계속하기로 재개. 12마디 완료 마디 보존·미완료 마디 재측정, 8마디 모의 전환 시 시도 초기화 |
| 메트로놈 | 기본 끔. 마이크 사용 중 켜면 스피커 소리 감지 가능성과 이어폰 안내 표시 |
| 8마디 마이크 미사용 | 개발 전달 명세에 따라 모의 판정. 시작 화면·결과에 표시하고 판정 방식을 기록 |
| 위젯·친구 | 위젯은 앱 안의 모의 화면이며 친구 목록은 샘플이다 |

평가 패널의 판정 모드·속도·자세 알림 방식을 확인한 뒤 참가자에게 전달한다. 저장은 사용한 브라우저에 남는다. 참가자가 바뀔 때는 기록을 회수한 뒤 상태 초기화와 참가자 번호 변경을 진행한다.

## Figma·콘텐츠 대조 결과

- 개발 전달 표의 색과 Pretendard 지시를 기준으로 한다. Figma 화면 일부의 Noto Sans KR 표기와 충돌하는 경우 개발 전달 표를 우선한다.
- 기타 아이콘은 Figma 원본 SVG를 앱 내부 자산으로 사용하며 원본 크기·회전을 확인했다.
- 최근 7일은 출석과 1분 이상 연습을 구분한다. 출석만 한 날은 출석 기록을 유지하며 연습 시간은 0분으로 표시한다.
- Em·G·C의 줄·프렛·손가락 배치와 개방현을 코드 음 구성과 대조했다. G와 Em→C의 전환 문구를 운지에 맞게 정리했다.
- 완주하기 설명을 현재 두 코드씩 진행하는 8마디 전환 연습에 맞췄다.
- 작은 화면에서 홈 캐릭터 크기를 제한하고 현재 마디가 악보 영역 안에 보이도록 스크롤한다. 템포 조절기는 디자인 색과 조작 크기를 적용했다.
- 홈 이어하기·다음 레슨 바로 열기·완주 후 곡 재연주 바로가기는 사용자 확인 후 반영한 동선 개선이다.

## 마지막 실기에서 확인할 항목

현재 전달 전 검증에서 프로덕션 빌드, 전체 QA 140개, 320·360·390px 모바일 화면 12개 조합, 운지·음 구성·연습일 구분·현재 마디 스크롤 검사가 통과했다. 이전 카메라·저장 복구 검증 내역은 [개발 기록](superpowers/plans/2026-11-12-pilot.md)에 있다.

1. 평가용 폰·브라우저에서 마이크 감지 기준과 박자 허용 오차
2. 카메라를 세울 위치·조명과 기타에 가려지는 손목·어깨
3. 실제 판정의 과한 알림·누락·처리 지연과 발열
4. 참가자 한 세션 완료 후 기록 복사와 다음 참가자 초기화

구체적인 실행 순서와 결과 양식은 [팀 테스트 안내](TEAM_TESTING.md)에 있다. 실기 결과가 도착하면 기준값과 재현되는 오류를 수정하고 같은 조건으로 다시 확인한다.
